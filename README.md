# python-100-days - Another Python Course/Bootcamp

To make this work you need to ...

* clone the repo
* install `uv` tool
* run `uv venv`
* run `uv sync`
* run `uv tool install ruff` (and `mypy`, `pytest`, ...)
* run `uv tool run ruff format 001`
* run `uv tool run ruff check 001`
* run `uv tool run mypy 001`
* run `uv tool run pytest 001`
* run `uv run python 001/hello.py`
